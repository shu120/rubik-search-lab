# Rubik's Search Lab

A Rubik's Cube solver and visualization project for exploring graph theory
and search algorithms.

## Goals

- Model the Rubik's Cube as a state graph
- Learn and implement graph search algorithms
- Compare search performance and solution quality
- Visualize solving processes with an interactive 3D cube
- Explore efficient algorithms for the 3×3×3 Rubik's Cube

## Planned Topics

- Breadth-First Search
- Bidirectional Search
- A*
- Heuristics
- Pattern Databases
- State compression

## Roadmap

1. Implement the cube state representation
2. Implement basic cube moves
3. Build a 2×2×2 solver
4. Compare BFS and bidirectional BFS
5. Add a 3D visualization
6. Extend to 3×3×3
7. Implement and benchmark faster search algorithms
